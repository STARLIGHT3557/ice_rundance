# 冰面炫舞（Ice Dance）

一款竖屏休闲竞速小游戏（单机 + 3 个人机对手）。

## 玩法
- 4 列通道，每一行随机有 1~2 片「草坪」，其余是「水池」。
- 点击下一行的草坪前进；点到水池会落水，1 秒后回到原草坪。
- 与 3 个人机对手同赛道竞速；第一个完成后进入 10 秒倒计时，倒计时结束结算。
- 完成者按用时排名，未完成者按进度排名。

## 特色
- 宠物选择：小猫 / 小狗 / 九尾狐（Q 版动漫风，背对玩家的俯视趴姿，带待机与跳跃动画）。
- 人机难度：新手 / 普通 / 高手 / 大师。
- 准备环节：3、2、1 倒数。
- 5 首原创洗脑 BGM（Web Audio 实时合成），比赛开始随机挑选一首。
- 设置：音效 / 背景音乐 / 震动 / 落水惩罚。

## 运行
直接用浏览器打开 `index.html` 即可，无需构建、无外部依赖。

│   ├── bgm.js          # 背景音乐合成

## 操作
- 主页：开始游戏 / 宠物 / 设置
- 游戏内：点击草坪前进；右上角 🏠 返回主页
